# 🎧 Spotify Clone

## Project Summary
**Spotify Clone** is a front-end web project that mimics the core UI and functionality of Spotify. Built using only **HTML**, **CSS**, and **JavaScript**, the application allows users to browse albums, view song lists, and control playback with a custom-designed music player. Songs are organized in local folders and displayed dynamically using a structured `info.json` file for each album. The user interface is fully responsive and styled to resemble the modern aesthetic of Spotify.

---

## Front-end 🌐

**Technologies Used:**  
- HTML  
- CSS  
- JavaScript (Vanilla JS)

### Features:
- 🎨 **Responsive UI:** Optimized for mobile, tablet, and desktop
- 🎵 **Custom Music Player:** Play/pause, next, previous, seekbar, volume control
- 📁 **Dynamic Album Display:** Automatically loads songs using `info.json`
- 🧭 **Interactive Controls:** Real-time updates to player status and seek progress
- 🔄 **Folder-Based Song Organization:** Easy to update or add new albums/songs

---

## How It Works ⚙️

- The app loads songs from structured folders, each containing an `info.json` with album metadata.
- JavaScript fetches this metadata and generates HTML elements to display albums and songs.
- Users can control playback with a fully custom player (not using `<audio controls>`).
- The interface mimics Spotify’s layout with a dark theme and interactive components.
